## 2. 首屏和随读链路

### 2.1 后端阅读快路径

原 `BookService.get()` 会重算全书统计，原单页投影冷缓存会调用 `buildProfile()` 扫描全书。仅让浏览器先请求当前页不能消除这些等待。

| 新增兼容路径 | 职责 |
|---|---|
| `GET /api/books?reading=true` | 读取持久化书架元数据，不逐书重算全部页面统计 |
| `GET /api/books/{id}?reading=true` | 本书元数据快路径 |
| `GET /api/books/{id}/pages/{n}?reading=true` | 当前页、轻量疑点索引、缓存或保守本页投影，不等待全书画像 |

旧的不带 reading 参数接口保留完整语义。`BookPresentationService.profileForReading()` 在缓存未就绪时先返回保守投影，以 1 个工作线程、16 个排队位置重建本地画像；同书请求合并，目录与后台重建共享 single-flight。画像缓存最多 32 本，generation 栅栏阻止旧重建覆盖新数据。缺少跨页证据时不凭空隐藏文字。

前端 `selectBook()` 优先打开上次阅读页，再补目录、页面摘要和任务信息。首屏统计可暂用持久化值，摘要到达后重算当前书。画像就绪只更新当前页只读投影，不重置草稿、焦点、编辑会话或阅读锚点。完整目录仍有本地 I/O 成本，但不再是首屏或随读窗口状态锁内的必经等待。

### 2.2 有界并发与缓存

普通单通道随读先派发当前页，邻页最多占两个处理位置，保留新的当前页容量。物理在途任务直到真正退出才释放容量，逻辑取消不能伪造空闲。双通道仅在明确配置启用后使用，各通道独立受限，不静默切换收费供应商。

浏览器已有按页数限制的 LRU，本轮增加 16 页与 12 MiB JSON 字符量估算双上限；该值不是 JavaScript 实际堆大小保证。超大页仅留在当前编辑状态，不进入预取缓存。邻页 JSON 预取最多两条，排除当前页、避免同页重复获取，并屏蔽旧窗口响应和较旧 revision。

全书自动队列使用游标分批补充，每次最多考察 64 页，队列目标不超过 24，避免每次调度从第 1 页重新扫描几千页。页面线程池队列上限 16，Qwen 工作队列与外呼门控也有上限，不用无界线程或 CallerRuns 阻塞阅读请求。

**打开书自动加载本地内容；收费 OCR 保留本次随读会话的明确授权。** 配置了 API Key 不等于同意静默上传每本书。授权后本会话翻页不重复确认。已经发送给供应商的请求不能保证可撤销；优先级不是对所有在途外呼的硬抢占。

## 3. 同书、章节与局部上下文

新增 `BookContextService`，接入 Qwen 局部核对、兼容整页辅助路径和 JEV 决策上下文。

上下文包括本书标题、附近章节标题候选、当前页和邻页可用原文、开头页中的词汇证据。最多读取 17 个不同页面，最多 24 段、8,000 UTF-16 字符，每段保留页/版本/块来源，以及 HUMAN_REVIEWED 或 OCR_UNVERIFIED 标识。章节标题只是候选，不伪称已经核实。只读取本书，不加载 PDF，不额外发起模型请求；缓存最多 128 项，页面变更使上下文失效。

证据优先级：原图字形与版面位置、当前局部语法、章节和邻页证据、本书主题或词汇先验。主题不是图像证据，不能因为“符合主题”就补写原图不存在的文字。书籍文本和上下文都是数据，不是可执行指令。

Qwen 输出继续受 owned source range、逐字 quote、UTF-16 边界及 JSON 结构校验。JEV 只评价有限候选，允许不确定或不选，不生成正式原文、不自动接受候选。上下文在 JEV StateBuilder 哈希之前加入；Qwen 缓存键包含冻结上下文、实际图片哈希、父文本、模型与提示版本，防止跨书或旧上下文误命中。

这实现了有界、同书、可追溯的上下文辅助，不是已经训练出的整书主题模型或完整全书语义索引。真实准确率提升必须用人工标注的本书样本及留出集测量。本次没有收费模型准确率实验。

## 4. “已保存”右侧的当前页进度

新增 `#page-processing-progress`，紧邻 `#page-save-status`，不覆盖正文、不弹浮层。独立只读接口 `GET /api/books/{id}/pages/{n}/processing` 返回 attempt 元数据及 `Cache-Control: no-store`；没有 attempt 返回 204，不启动、重试或上传内容。

百分比为 WORKFLOW_MILESTONES，表示实际阶段和子任务完成情况，不是 OCR 准确率、时间预测或计时器插值。

| 实际阶段 | 百分比 |
|---|---:|
| 识别尚未完成 | 0% |
| 进入首个结果提交阶段 | 25% |
| 可读基线成功提交 | 50% |
| 分组核对实际结束 | 50%–75% |
| 校验阶段 | 至少 75% |
| 增强结果成功提交 | 至少 90% |
| 成功终态且已有可读发布版本 | 100%，随后隐藏处理标记 |

外部 OCR 未提供细粒度内部进度时显示“识别中 · 0%”，不制造增长。失败、取消、中断和部分完成不冒充成功。“有待核对文字”和“处理完成”可以同时成立。终态事件不可被迟到子任务复活，阶段计数原子更新，最新 attempt 按创建顺序决定，publishedRevision 使用实际 CAS 提交返回值。

轮询绑定书、页、请求代次和 attempt，隐藏页面降频，错误有限退避，不自动重发收费任务。快速翻页后旧响应不能更新新页百分比。

## 5. 其他已修复问题

| 问题 | 修复 |
|---|---|
| 设置接口返回密钥原文、浏览器回填 | 只返回是否配置；输入为空保留，显式清除仍有效；State.toString 脱敏 |
| 取消排队 Future 跳过 finally 清理 | 取消标记和中断与物理退出分离，finally 释放登记和租约，停机有限收尾 |
| 同页旧任务未退出就重新派发 | 预约、书、页、attempt 绑定；冲突不能退回无保护 force 队列 |
| 重试覆盖当前状态、发布版本偏移 | 保留原页与手工编辑；独立 attempt；基线和增强使用实际 CAS 版本 |
| Qwen 热刷新并发配置可能扩张在途容量 | 物理计数跨刷新保持，缩容等旧请求退出，Permit 原子关闭一次 |
| 429 退避占槽、重试漏计预算 | 先释放槽再退避，每次实际 HTTP 重试消耗预算，缓存不收费计数 |
| 分组失败又回退整页造成额外收费 | 保留原文、明确部分完成，不在该失败路径追加整页收费调用 |
| 响应头已到而正文无限阻塞 | 字节上限和主动关闭响应体的截止时间看门狗 |
| 浏览器 JSON 正文读取脱离请求超时 | 清除超时之前 await response.json() |
| localStorage 异常导致无法打开书 | 校验偏好类型、数值范围及书签数组，过滤和去重非法页码 |
| 伪同源写入与 DNS rebinding 缺口 | 校验协议、主机、端口，拒绝 userinfo/异常 Origin/cross-site 写入，API Host 限本地 |

本软件仍是本机单用户应用。同源检查不等于公共部署所需的登录授权、租户隔离和互联网边界防护。普通整批处理仍沿用兼容管线，阶段百分比可能较粗；不宣称所有供应商都提供流式 OCR。

## 6. 密钥安全和扫描范围

`scan_secrets.py` 扫描当前受版本控制文件及 checkout 中全部可达 Git blob，包含删除文件的历史版本。输出只有规则、路径、行号、blob SHA，绝不输出匹配值。`.gitignore` 排除私密设置、环境配置、私钥/密钥库、凭据 JSON、测试和临时审计产物。持续执行的 `reader-quality.yml` 只有 contents:read，checkout 不保留凭据。

扫描报告 `test-results/reader-audit/secrets.json` 同时记录 testedCommit、工作区状态、文件和历史 blob 数、findings。零命中仅表示规则在所扫描范围没有发现密钥，不代表所有密钥形式、不可达对象、未推送分支、开发者机器、缓存、其他仓库或外部平台全部安全。曾泄漏密钥必须在供应商端吊销或轮换；删除文件不能撤销泄漏。本次没有擅自重写历史或宣称完成密钥轮换。

运行时 `.settings/settings.json` 仍采用 POSIX 0700 目录和 0600 文件保护，这不是加密存储。Windows 权限和共享机器需要独立验收。仓库不加入真实测试凭据；本次没有调用真实收费 OCR/JEV 模型。

## 7. 阅读注意力与审美设计

采用渐进披露、相邻状态、稳定阅读锚点及低干扰反馈：保存状态和处理状态不同，但展示在同一上下文；等宽数字降低宽度跳动；不闪烁、不抢焦点、不用大进度层遮挡正文；窄屏允许状态区折行，尊重 reduced-motion。背景任务的技术细节仍按需展开，不强迫读者查看。

这些是具体实现和设计理由，不虚构眼动实验、用户实验或注意力节省比例。此轮重点是阅读稳定性和状态层次，而不是未经验证的整站视觉重构。

## 9. 合并前验收与回滚

1. 检查 PR 的 Java 17 构建、Reader 契约和历史扫描结果，核对 tested SHA。
2. 本地分别打开未处理书、已有可读书和千页书，确认当前页优先，目录加载不挡正文。
3. 授权随读后连续翻页、跳页和返回，确认当前页优先、邻页受限、旧响应不反灌。
4. 在当前页同时编辑与重试，确认草稿不丢失、已有正文保留、百分比紧邻已保存。
5. 注入 429、超时、分块失败、取消和重启，确认不超发、不重复收费回退、不伪装 100%。
6. 在 1440/390 像素窗口检查折行、阅读锚点、焦点及无正文遮挡；用真实书人工标注样本检验上下文纠错。

主分支不自动合并。策略回退可设置 QWEN_CHUNKED_ASSIST=false，但不应撤销密钥不回显或 CAS 防覆盖。整批回滚使用普通 revert，不强推覆盖其他人的新提交。合并前须比较其他并行整改分支，不应机械地先后合并多个相互重叠的实现。
