## 2. 异步归属和草稿保护

书籍manifest、页面正文、可选元数据及目录具有独立请求归属/取消信号。切书使旧归属立即失效，迟到的A-B-A响应不能替换当前书页；旧失败后的滚动恢复也要验证当前导航。

当前可见页刷新不拆掉旧DOM、不清空编辑会话，失败后仍可阅读旧正文。读取期间开始校对时，结果进入待更新提示，不覆盖草稿。没有修改人工提交的版本校验或覆盖授权。

后台摘要/计数/目录不拥有正文；其请求开始后若收到较新页面/窗口元数据或产生编辑，会拒绝旧投影回写。书籍快照计数明确标为“上次记录”，不伪装成重新全书核验后的准确计数。

已有随读会话恢复增加标签页代次、书籍及sessionId校验。迟到成功或失败不清除其他新会话的sessionStorage，不在停止后恢复旧会话；有效恢复只恢复可停止能力，不因此发起新的POST。
