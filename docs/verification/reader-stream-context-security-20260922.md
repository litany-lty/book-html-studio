## 三、打开书的实际行为

打开书 → 恢复本书上次阅读页 → 当前页正文/原稿优先呈现 → 异步目录与摘要 → 只读邻页预取。

对于已经主动授权的随读处理会话：当前页优先进入处理队列，邻页使用剩余容量；OCR 基线先持久化并可读，Qwen 小任务随后增强。默认主通道并发为 3 的情况下，当前页就绪时后台最多占用 2 个主通道槽位，预留 1 个给跳页；前端只读邻页预取上限为 3。这两种并发不是同一资源池，不应把它们相加当作云端额度。

边界：打开书不会默认授权云端外发、收费 OCR 或整书处理；已在执行的物理云请求不能承诺即时抢占或退款。若已有批量任务占用资源，需要遵循现有任务协调，而不是额外创建无限线程。

## 四、以本书为范围的文字推断

新增 `BookContextService`，向 Qwen 文字校对、兼容整页辅助路径及 JEV 有限候选评估提供同书上下文。

上下文包含本书标题提示、有限回溯找到的章节提示，以及当前页/前后最多 3 页的可用原文片段。章节查找仅有限回溯，不为一个疑字同步遍历整书；缓存有容量上限并随数据更新失效。片段携带书籍、页码、revision 和来源限制。

只使用正式页中的 original，不使用未确认候选、模型建议或其他书。优先人工确认或达到可信度筛选的无疑点片段；缺失上下文时明确缺失，不先凭空生成“全书主题”再反过来证明疑字。

主题、章节和相邻文义只提供语义先验，不等于图像证据。专业术语、人名、异体字或原书自身笔误不能仅因“不够通顺”被改写。JEV 继续只对有限候选排序；未确认假设不静默覆盖 canonical 原文。

这不是新增整书向量库或自动学习术语词典，也没有测得 OCR 正确率提升百分比。`question-template-v3-book-context` 取代 v2；旧模型校准结果必须重新核验，不能直接继承“已校准”状态。

## 五、当前页进度和注意力设计

`#page-processing-progress` 紧随 `#page-save-status`，显示形式如：`已保存  可读 · 整理 77%`。窄屏将保存与处理进度编组，避免两者独立折行而失去对应关系。

进度来自真实阶段事件和已结束的核对组：准备 0、OCR 10、基线提交 50、结构整理 60、分组核对 65～90、校验 92、发布 97；仅成功终态显示 100。它是工程阶段加权，不是耗时比例、ETA 或文字准确率；提示说明这一点。不使用定时器自增数字。组数中的失败/跳过代表该工作单元已结束，但未完成或失败结果不会伪装为成功终态。

采用弱强调文字、等宽数字、预留数字宽度和非浮层布局；详细诊断继续按需展开；保留键盘焦点、跳到正文和减少动画偏好。切页、切书、旧任务迟到响应不会把其他页的百分比贴到当前页。隐藏标签页暂停后续轮询，失败只重试状态 GET，不自动补发收费 OCR。

这些是降低干扰的设计措施，不是经过用户实验确认的认知负担下降数值。100% 仅说明当前处理管线结束，质量徽标仍可提示待核对文字。

## 八、复核与回滚

先查看 PR 的 `CI`、`Reader regression` 和 `Redacted secret guard`，确认验证的 checkout 与预期 HEAD/合并预览一致。到隔离分支手工打开一本已处理书，检查恢复阅读位置；打开一本未处理书，确认不会未经许可自动消耗云额度；主动启动随读后连续跳页，并在增强期间人工编辑，确认旧任务不会覆盖编辑。

Qwen 分组默认开启，可通过 `QWEN_CHUNKED_ASSIST=false` 回到保留的整页路径。回滚不要通过绕过 revision、人工保护、外发许可、预算或把 PARTIAL 强改 SUCCEEDED 来掩盖问题。部署前备份本地 data，并保持既有配置文件私有权限。

后续优先验证：真实不同版式样本与稀有术语；单书章节超过当前回溯窗口时的主题召回；实际服务器的首屏 P50/P95、跳页等待、队列长度、堆占用和成本；长期多书交替阅读时的缓存失效率。若这些指标成为瓶颈，再评估持久化章节索引、增量版式摘要或分离前台/后台模型调度，不在未测量前直接堆并发。
