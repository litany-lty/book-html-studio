## 1. 已复现问题与实际修复

| 缺陷 | 修复 |
| --- | --- |
| 显式撤销后启动/导入又创建全局授权 | 默认初始化消费一次持久标记；任何既有历史授权都不被解释为首次安装，撤销和过期不会自动续成永久授权 |
| 每书授权副本可能绕过中央撤销 | 中央consents目录为唯一授权事实；旧每书副本不再授予权限，不依赖跨实例的旧内存缓存 |
| 损坏的远端回执被忽略后重新提交 | 有界严格恢复与持久quarantine；恢复不完整拒绝新提交；已知有效远端任务仍可续查 |
| 旧遥测成功覆盖更新的权威attempt | 比较存储层attempt身份、代次和终态后投影；同代次不同ID为UNKNOWN，不冒充旧成功 |
| PAGE1提前冻结核对分母，实际4组仅1组就获得完整权重 | PAGE计数不冻结REVIEW；先校验工作计划再修改计数，不吞掉冻结冲突 |
| 子计划哈希引用被替换的父哈希 | 父计划只冻结阶段权重与身份；核对分母属于子计划，冻结后父哈希稳定且子哈希可验算 |
| 完整计划重载接受另一书页或替换已完成单位 | 校验书页、代次、版本、阶段、哈希及冻结状态；拒绝后原计数和哈希不变化 |
| 手稿非正常终止但JSON可读，被当作完整转写 | 手稿与自动自检共用ModelCompletion，要求单一stop文本结果，拒绝截断、过滤、拒答或工具调用结果 |
| 人工替换未进入上下文，旧词仍标为人工已审 | 只读EvidenceTextResolver应用已确认原字替换；原始OCR不改，未知候选遮蔽，无效偏移不当作证据 |
| 取消/中断任务无errors时仍显示全部成功 | 独立任务文案投影同时检查终态和结束页数；本轮完成不等于字字准确 |

## 3. 升级与故障恢复边界
