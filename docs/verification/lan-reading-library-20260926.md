# 以阅读为主的局域网共享书架

基线：`main@a6177771313a1217c02f00edb9d34d1a7445ffdb`。本轮按用户追加方向实施：部署后上传 PDF，之后在同一局域网回到书架阅读。没有继续增加模型或校对配置。

## 产品边界

沿用单服务器共享书架，不凭“用户”一词擅自增加账号、私有书架或公网网盘。PDF、页面及已发布结果保存在服务器，书架供有读取权限的设备共享；阅读位置、显示偏好及书签当前留在每个浏览器本地。同一浏览器同一地址可继续上次位置，另一设备不会被这台设备的翻页覆盖，但没有账号级跨设备同步。

## 已实现

1. 首页改为书架：书名/文件名搜索、本设备最近阅读/上传时间/书名排序、每次最多24张卡片。主操作为开始或继续阅读，读到的页码来自本浏览器，不把处理百分比冒充阅读进度。不预读全书正文、不渲染每本书封面。
2. 返回书架复用原切书生命周期，离开前保存有效当前页位置，未加载/错页响应不更新阅读记录。未保存草稿继续受既有确认和提交保护约束。关闭/刷新浏览器后从书架重新选择即可续读。
3. 接入真实浏览器上传配对：本机管理员生成十分钟上传码，远端输入后取得READ+UPLOAD。凭据以HttpOnly/SameSite=Strict Cookie保存，HTTPS加Secure；不在URL、DOM、localStorage或响应JSON回显浏览器凭据。24小时有效，服务器重启后上传需重配；原图与书架不丢失。
4. 上传权限独立于EDIT、PAID、MANAGE。旧程序化配对入口也只发READ+UPLOAD，不能拿同一个上传码换取高权限。明确配置的既有EDIT/PAID令牌可继续按能力使用，MANAGE保留全能力。只读用户默认不自动派发收费识别。
5. 修复真实计费路径的权限分类：原规则只匹配`/api/jobs`，漏了真实`/api/books/{id}/jobs`、reading-window和decision-jobs；云端授权及阅读策略写入现在也需管理能力。未识别/有歧义编码的写路径不继承EDIT权限。取消已运行共享任务同样不授予普通上传读者。
6. 浏览器Cookie写入要求Origin或Referer同源证明，拒绝跨源。历史URL参数配对凭据停止接受；显式请求头仍可用于受控程序化客户端。默认公开读取只限部署者保护好的局域网，不能等同“公网访问安全”。
7. 上传读者不展示工具配置、付费处理或校对入口；书架管理仍是管理入口，原稿与当前页读取保持可用。既有本地自检和已授权解析链路中的语义自检仍默认开启。
8. 补充常驻部署示例，BOOK_DATA_DIR固定在发布目录外。systemd unit仅是示例，没有安装、启动或更改用户现有服务。

## 验证设计

新增LAN权限回归先在旧实现执行：真实计费路径及授权写入不能被EDIT阻断；浏览器配对入口原先不存在。原失败记录在仓库外保留。新增测试覆盖COOKIE能力、跨源、缺失来源、拒绝URL凭据、退出仅撤销本设备、重复Cookie、HTTPS Secure、旧入口不升级权限、未知编码路径。

PDF持久性测试用PDFBox创建真实两页PDF，调用实际上传服务，再完全关闭及重建BookStore，验证书架仍可发现同ID/原始PDF逐字节不变，轻量列表不打开Page JSON。不调用云模型。

新浏览器专项使用真实Spring HTTP、实际Multipart PDF上传和同一临时数据目录的两次服务启动。独立浏览器模拟管理员、上传读者和第二台只读设备；局域网peer由仅在test classpath编译的Servlet包装模拟，实际监听仅回环，没有生产转发头信任、没有对外开放测试端口。验证配对前不上传、配对后入架、原稿字节、HttpOnly、页码续读、第二浏览器隔离、重启保留、重启不复活旧令牌、取消配对不上传、无模型派发和无外部请求。

浏览器脚本首次运行遇到Python/Java临时目录差异；仅为测试子进程显式传入其自有临时目录，未放松目录校验。随后因CSP拒绝字符串求值，改用函数形式的Playwright等待谓词，未增加unsafe-eval。两次是测试驱动适配错误，不作为生产缺陷复现或绿色验收。

正式验收以最终提交的完整Maven、原导航/工作台/专注/扫描回退、新上传/重启浏览器、秘密扫描和合并后main产物为准。测试跳过项单独统计，先前修改过程中构建的结果不代替最终版本验收。

## 明确未完成

账号级读者身份、私人书架与跨设备位置同步未实现；当前书籍是共享资源。上传配对不是付费处理授权；扫描PDF未解析时可阅读原稿，由部署者在受控入口执行解析，普通上传者不会因此自动获得模型调用权。大PDF导入仍需完成页面初始化，失败或超时先查书架再重传；没有在本批实现断点上传、上传幂等和磁盘总量配额。

真正逐页增量索引、手稿即时区域发布、剩余供应商整合、真实遮蔽手稿准确率及费用、大书负载、真实Wi-Fi设备/网络断开和硬件断电验收仍保留。常规服务重启不等于硬件断电。

启用时备份完整BOOK_DATA_DIR，按README使用固定目录和专用服务账户；不要把文件放在临时容器层。权限变更不会把撤销凭证恢复，可能使旧仅EDIT的LAN客户端需要重新以上传码配对。私有密钥不要放进unit或Git。用户现有数据、密钥、运行配置、网络设置和日常服务均未修改。
