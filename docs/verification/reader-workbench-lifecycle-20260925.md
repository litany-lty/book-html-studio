# 阅读／校对模式与工作台生命周期整改

日期：2026-09-25。基线：`main@d526a7b4a6b316093bf14d38ab940fa60d8724ed`。
范围：真实阅读器的校对入口、桌面持续校对、手机抽屉、专注返回、局部证据读取与资源释放。

## 1. 真实复现

基线浏览器直接运行实际前端、合成书籍与本地证据：21项检查中10项断言失败，0页面脚本异常、0变更请求、0外部请求。
其中包括：桌面“校对”只打开空栏；原稿阅读在隐藏侧栏挂载编辑器；连续翻页后编辑框落后于当前页；进入专注后隐藏工作台仍保留资源；手机遮罩关闭没有同步模式，下一次开启按钮状态反转。
失败产物保存在仓库外 `book-html-studio-verification/reader-workbench-lifecycle-20260925/baseline-browser`。

## 2. 模式与显示只有一个所有者

`reader-mode.js` 统一管理模式、校对栏 open 状态、两处入口、遮罩和模式通知。`app.js` 不再另注册一套手机校对点击／关闭动作。
模式变化通知真正挂载或卸载当前页工作台；不会仅改变CSS或把原稿视图当作校对许可。
桌面校对是用户主动选择的持续布局，翻页后保持可见，并且内容绑定新页；手机翻页仍关闭临时覆盖式抽屉，同时回到阅读模式。
切书或无当前页时移除旧编辑DOM，防止用户面对上一页的表单。退出校对不清除 `state.blocks`、未保存标记或未确认替换，重新打开继续使用同一草稿。
手机关闭时焦点回到实际可见的打开按钮；Escape尊重已打开的原生对话框，不把其下的校对模式一起关闭；重复初始化不增加重复切换监听器。

## 3. 隐藏资源与独立原稿

离开校对或进入专注时：停止该面板的决策读取／轮询，取消面板自己的证据元数据GET，清空疑点、逐块编辑和结构列表，解除整页预览图片引用。
这不是取消服务端决策或OCR任务，也不承诺浏览器中止网络后服务端渲染已经物理结束。正文中的用户主动证据查看保持独立，不因关闭校对被当成授权撤销。
整页原稿折叠区仅展开时绑定图片，折叠后释放；可见疑点的块级回退仍允许读取原页作为裁切依据，不能为了通过“没有整页请求”的测试而删除必要证据。
新增测试最初用“所有整页图片请求均为0”验证折叠区，误把合法块级回退算作折叠区读取；改为直接检查该独立预览的src，并实际展开／收起验证。没有让合成证据假装取得真实OCR定位。

## 4. 专注退出不再误触进度跳页

实际复查还发现“退出专注”按钮的click会冒泡到进度容器，布局恢复后旧点击坐标可能落在滑条范围，从而意外跳页。容器现在忽略按钮、链接、输入控件及已处理事件；保留原生滑条与非控件区域操作。

## 5. 回归与验证口径

增加6项真实 `reader-mode.js` 模块测试，覆盖桌面/手机单次切换、可见焦点、程序化进入、重复初始化、竞争导航与响应式布局、对话框Escape。
实际工作台浏览器回归扩充到30项，覆盖旧10个失败场景、折叠原稿、页2/页3、专注进入退出、手机遮罩/重新开启、草稿保留与键盘退出；本机连续3轮全部通过，0脚本异常/0变更请求/0外部请求。
旧完整导航31项、专注47项、扫描回退13项继续执行，没有降低或选择性跳过。本轮新增校对浏览器回归也加入Reader integration；模式模块测试加入完整CI。
40条本机脚本/语法验证命令通过。完整Java17构建、实际隔离Spring服务冒烟及最终主分支CI，以对应提交产物为准；没有新增Java用例，不因增加Node/浏览器测试虚增Java数量。
`FrontendBoundsTest` 的旧结构断言把“原稿视图”当作工作台挂载条件，现调整为真实可见校对模式且非专注；行为由新浏览器回归验证，未只用字符串匹配声称完成。

## 6. 数据与运行保护

没有调用收费OCR/模型；没有读取或修改真实书籍、密钥或私有配置；没有重启日常服务。默认可理解性自检、原文保护、授权/预算/任务取消语义、当前页优先、左右专注翻页和底部进度条保持原机制。
工作台关闭不保存也不清除草稿；服务器任务不由模式改变自动终止。首次进入校对会按需读取本地证据元数据；无精确位置时保留原有保守块级回退，不能把此项称为真实识别精度提升。
没有新的持久数据格式。代码先在隔离工作树验证，通过后合并main并清理本轮分支，失败证据保存在仓库外；运行中的旧服务不会因git同步自动升级。
