# Web 样式热修复（U7 之后，用户报障）

复现：独立端口合成书 + 本机 Chrome headless（1440×900 / 390×844）截图。

## 问题与根因

1. **移动端工具栏重叠**：基线移动端 toolbar 按 3 按钮设计（`nowrap` + 后续媒体块
   `min-width:72px`）；U1 新增第 4 个“校对”按钮后 390px 下溢出重叠。
   修：620px 下工具栏改为单行横滑（`overflow-x:auto`，子项不收缩），
   44px 触控目标保留，尾部按钮横滑可达（已实测）。
2. **技术诊断常驻正文旁**：U1 把细节移到 `#quality-diagnostics`，但该元素默认可见，
   等于没搬家。修：诊断区默认收起，页头加“详情”按钮按需展开（`aria-expanded`）。
3. **桌面底栏进度条偏左**：校对栏关闭后 `.reading-progress` 仍预留右侧 365px。
   修：阅读模式下宽屏右偏移归零。
4. **移动端正文首屏预算**：双行工具栏把 `#paper` 顶到 312px（>300 断言）。
   单行化后 263px，断言恢复。

## 验证（actual）

- `node --check app.js` OK；`mvn test` 365/365（一次满载 @TempDir 清理抖动，重跑全绿）。
- `cdp_reader_ux.py` OVERALL PASS（35 项，含“手机正文首屏空间”）。
- 桌面/移动截图复检：诊断收起、无重叠、无横向溢出、零脚本异常。
