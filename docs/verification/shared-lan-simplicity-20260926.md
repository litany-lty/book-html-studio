# 共享局域网阅读：取消默认配对与减少不必要配置

基线：`main@3876e350d89e51c445dc02031555ba05051402c2`。用户确认：尽可能简单，非必要不配置；局域网内所有书籍是共享书架。此要求替代上一批“默认上传也必须配对”的产品选择。

## 本批改变

普通直连可信局域网：打开地址即可读共享书架和上传PDF，无账号、无配对码、无共享开关、无上传凭证续期；服务重启后仍可直接上传。仅授予READ/UPLOAD，不能改共享正文、修改云授权、启动付费任务或管理设置。

隐式上传只认实际peer的私网IPv4、链路本地、IPv6 ULA/链路本地。不做DNS解析来判断主机名，拒绝非标准IPv4、公网/未识别地址；有Forwarded/X-Forwarded-For/X-Real-IP的代理连接不借此冒充直连LAN。Host与同源Origin/Referer保护保留，非本机上传必须有同源证明。既有显式可信代理配置不在本批改写，它仍需部署者正确保护。

明确开启过read-requires-pairing的旧部署仍按旧边界授权，不把“少配置”当作取消现有安全限制。受限或非默认接入才显示访问授权。默认页面隐藏该入口，取得能力投影后上传不再每次额外读取设备状态；服务端每次独立校验，拒绝后不会自动重试上传。

所有书籍继续属于服务器共享书架。页码与书签按浏览器本地保存，仅是读者位置隔离，不是私人藏书；没有引入个人账号、私密书架或跨设备配置。普通读者的处理任务入口收起，已显示正文、原图、阅读进度与默认自检链路保持原有能力。

从阅读页返回书架或重新切回书架标签，自动刷新轻量元数据；不增加计时器/后台轮询、不读取全书正文。并发刷新合并为一个GET，迟到响应不能覆盖其间已发生的上传/改名/归档。刷新失败仍保留原书单，后续成功清除过期失败提示。

README按默认流程重写：必要部署项是固定持久数据目录；不新增配置字段，原端口和共享模式默认沿用。密钥和付费处理权限仍是部署者职责，普通用户不填写模型通道。

## 验证与原失败

新增8个后端回归，在旧实现上5个断言失败、0执行错误；包括私网无需配对上传、能力投影、重启、同源证明与“localhost”伪peer边界。其余3项原先已经安全的拒绝/显式受限场景保留。新增4个Node场景覆盖隐藏非必要设置、刷新单飞、并发上传后拒绝旧列表、失败重试。

原配对测试仍运行：其模拟peer为非私网地址192.0.2.50，验证不能静默取得LAN权限；生成配对码改由真实本机管理员API调用，默认页面不再增加配对按钮。Java既有受限配对流程显式声明受限前提，另保留默认/受限两套上传断言，不删掉受限权限保护。

新增`browser_lan_library.py --direct`使用同一真实Spring服务、PDF上传、磁盘保存和两次进程启动，只在test classpath将peer模拟为192.168.1.50。检查无需配对、无Cookie、无配置读写、重启无需重配、另一浏览器返回书架自动发现新增书籍，以及后台不派发收费任务。两种模式都只监听回环测试端口，不调用收费云服务，不改生产转发头信任。

首轮修改旧代码时读取的XML和日志保存在仓库外；完整Maven、三轮相关回归、旧四组阅读浏览器、新两种共享书架浏览器与扫描的最终结果，以合并提交的CI证据为准。不能把中途修改源码时的构建算作最终验证。

## 边界

“同局域网”是受信任网络内的共享使用，不是公网鉴权；未认证物理Wi-Fi、反向代理、真实手机及大规模压力。上传限制沿用现有单文件大小/页数限制，磁盘总配额、断点上传与幂等尚未在本批实现。原有增量索引、手稿即时发布和真实OCR准确率专项也未因此关闭。

未读取或改写用户真实书籍、密钥和运行配置；未安装服务、开放端口或重启日常应用。升级后需使用同一持久目录；本批没有改写书籍/任务日志格式。配置项减少不等于放宽账本、人工版本、提交身份或原稿保护。


## 本机执行边界

本机浏览器组合验收指令被执行工具以“无法确定请求安全状态”拦截，没有运行，也没有改用其他本机包装器重放该浏览器指令。因此本批不能引用上一版浏览器结果或宣称本机浏览器通过。已单独执行不启动服务、不发网络请求的8项Node模块检查和3份JavaScript语法检查，通过；先前已启动的完整Java回归继续独立执行。合并必须另核对仓库正常CI提供的当前提交浏览器结果，CI未通过就保留草稿。
