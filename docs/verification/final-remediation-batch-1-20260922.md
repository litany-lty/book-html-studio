## 2. 已落地的行为

### 设置接口与前端

GET／PUT 的安全视图不再返回 Paddle Token、PP-OCR Key／Secret、Qwen Key 或 JEV Key；保留 configured／是否已配置标志、普通设置、版本检查、工作租约、本机会话 CSRF 和 no-store。

新增 `secretUpdates` 显式写入／清除语义；缺省或空串保持原值，掩码不可成为凭据，同一字段混用旧输入与新输入被拒绝。前端不再回填已保存密钥，关闭设置窗口会清空输入。内部 State 的诊断字符串也已脱敏。

**重要限制：当前 `.settings/settings.json` 仍明文保存运行时凭据，仅有现有私有文件权限。SecretStore、ENV_ONLY／AES-GCM 密文模式和迁移尚未实现。不能将本批描述为“密钥全面安全”或“无明文落盘”。**

### 任务、原稿与版本

同一已接收重试操作先查幂等记录，再判断新操作的版本新鲜度；指纹纳入 revision、通道、版式、增强与人工覆盖参数。运行中和发布后的原操作重放不重复派发；参数变化和新操作的旧 revision 仍拒绝。

批量及随读均不再为开始任务而把已发布页面写成 PROCESSING。新稿实际提交前，旧稿内容和 revision 不动。随读基础稿及增强阶段采用 `commitPage` 返回的实际 revision，不再手算偏移。

删除了随读重试被拒后仍可能进入未经校验 `force=true` 队列的旁路。随读进度使用已登记 attempt 的 UUID／generation；准入 journal 写入失败时不派发处理。初始 OCR 异常、取消和工作线程退出增加统一收尾。重启不再仅凭 READY 或更大 revision 猜测某 attempt 成功。

关闭任务服务会阻止新准入、取消排队任务、在不持有准入锁的情况下有界等待工作线程 finalizer；到期仍未结束会明确报错，不把“发出中断”当成已退出。

**限制：幂等操作记录仍在内存，未实现完整持久重放／过期墓碑；批量与随读还未合并成规范要求的唯一页级执行引擎；BookStore 精确 attempt 提交门禁和 commitId 跨文件恢复日志尚未完成。**

### 进度归约与传输资源

最新进度改按同页 attempt 序号选择，不再比较不同任务的事件数。归约、计数和快照在同一锁内完成；支持 unitId 去重、冻结已开始完成计数的分母、终态拒绝复活。测试包含 100 个并发终态和重复上报。

QwenRequestGate 改成稳定资源计数：并发准入与后台计数原子变更，刷新不会新造许可，降低上限时自然 drain，重复关闭只归还一次。队列只保存轻量等待身份，并给前台保留排队位置。此处的准入计数不是物理付费发送账本。

前端成功响应的完整 JSON body 纳入超时／取消生命周期。BoundedHttp 将 body 读取从 HTTP 推进池隔离，提交 body 读取任务被拒时也会关闭已获得的流，并保留总期限和响应大小上限。

**限制：快照仍为兼容 V2＋attemptSeq，不含 V3 固定权重百分比。所有模型入口的发送预算、429 退避、调用日志 fail-closed、图片驻留预算和真实物理在途治理尚未全部接通。**
