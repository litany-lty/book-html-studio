## 对使用体验的改变

### 阅读和离线包

- 快速翻页、换书后，旧目录/疑字/广告的延迟回调不再抢走新页面焦点；同页后台重读的旧错误也不再覆盖新会话。
- 进度滑杆一次操作只提交一次导航。省流量模式会取消已有预取，停止请求失败时不会误报已送达。
- 自动刷新正文时，以当前可见块的真实视口位置恢复阅读位置，避免把不同坐标系混用造成跳动。
- 离线目录不再为了生成标题读取全书。14 页实测包首次仅加载当前 1 页，逐页访问后最多驻留 10 页，已完成的分页 script 节点不残留。
- 页面缓存释放后重新访问，真实 IndexedDB 中的校订仍会恢复。损坏的书签和阅读偏好不会阻止打开书籍。
- 离线文件缺失会显示可恢复错误，并由用户点击重试。修复前同一缺失页在约两秒内连续请求 416 次，修复后只请求 1 次；恢复文件后可重试成功。
- 目录跳转到尚未加载页面时，数据到达后继续定位到所选标题；延迟聚焦再次检查当前页面和目标。

### 解析与校对保真

- Baidu/Paddle 按物理坐标判断横竖排，避免宽页、长页在归一化后方向反转。
- 竖排页已有人工确认或疑点范围时保留原结构，防止重建/合并丢失 `issues`、简体内容或人工确认状态。
- 原文标题使用对应原字确认值，简体显示使用简体确认值；不把模型建议或简体确认自动写成原文。
- 非有限数或越界几何不作为书眉证据；证据文本拒绝无效 UTF-16，最终输出长度也受限制。
- 候选筛选容忍空项并尊重零上限；模型任务的短尾组不再突破块数/字符预算。
- 目录恢复严格检查完整、单一文本结果；过滤中止、工具调用中止、多选项或拒绝响应不会冒称恢复成功。

### 调度、取消与用量

- 同一个延迟调用只有一个待执行所有者，取消、立即回调、关闭和拒绝调度都能正确清理登记。
- 进度日志回放保留已完成阶段，修复实测 67% 在恢复后回退为 17% 的问题；重复完成事件不会重复计数，同代不同尝试不会覆盖原日志。
- 合法替换工作计划后，恢复使用最后一份计划的上下文身份，与计划哈希保持一致。
- 多本书的阅读预约分别生效；打开 B 书后仍能重处理 A 书，携带错误书籍路径的停止请求不能停止其他书的会话。
- 取消后的资源准入、租约扩容、图像分离/关闭、子图引用和编码流关闭均保证唯一所有者，避免提前释放或遗漏回收。
- 手稿恢复数据的容量维护能遍历后续条目；已取消的 OCR 不继续进行编码或进入客户端。
- 用量账本读取保留纳秒时间精度。已实际复现并修复同一记录在下一页再次出现的问题，独立 HTTP 检查恢复为稳定的 50 + 6 条。

### 导入、搜索和导出一致性

- Windows 上传路径会正确提取文件名；文件名长度按 Unicode 码点截取。
- 页码数字溢出、空范围段、末尾逗号和无效总页数明确返回 400。
- 在线搜索在内层循环严格限制 500 条；空白简体字段会回退原文，持久索引与回退搜索行为一致。
- 离线检索覆盖段落完整简体与繁体原文，修复第 120 字之后内容无法命中的问题。保留 20,000 条限制，增加 8 MiB **文本字节**预算；超限时明确提示索引不完整，分页正文仍完整导出。
- 导出标题、推荐摘要和目录都使用创建时捕获的内容。空推荐集合不会在写包时重新读取新推荐，人工目录修改也不会混入正在输出的旧快照。
- 框架的非法参数、缺少文件和错误 HTTP 方法保留其 4xx 状态及必要响应头，不再被统一误报为 500。
- 启动脚本把端口作为有界十进制输入处理，避免前导零的八进制错误和超长数字溢出。
