# 100 轮优化：执行计划与验收口径

起点：`main` / `da838c32ee744f786070c45031a40099726f0045`。执行分支：`optimize/100-rounds-20261107`。

## 目标

沿用现有 Java 17 / Spring Boot 3.4.10、原生浏览器模块与文件存储架构，改善 PDF 阅读工具的完整使用链路：共享书架 → 导入 → 当前页优先阅读 → 解析与校对 → 返回阅读 → 离线导出。正文优先，少配置，进度真实，保留原文与人工校对语义。

## 轮次口径

一轮对应一个具体问题假设：读取有关实现和消费者，检查或复现，必要时修复，再验证并记录结论。测试数量、格式调整、重复执行同一检查均不增加轮数。未发现缺陷时记录「检查完成，保留现状」，不能记作一项修复。需要真实模型、真实书籍或外部条件的结果单独标明未执行。

每个模块维护一份连续记录，列出具体目标、证据、改动和验证。并行模块互不编辑对方文件；跨模块问题交由主线程协调。全部结束后统一复核差异和受影响链路。
