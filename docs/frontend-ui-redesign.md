# 纸页工坊 前端体验改造：诊断与方案「宣纸墨青」

> 范围：UI / UX / 易用 / 性能 / 用户体验度。参考 beautifului.dev · beui.dev · rareui.com · transitions.dev · shadcn/ui。
> 证据：真实浏览器截图 × 12（桌面 1440 / 手机 390，覆盖阅读、原稿、校对栏、任务面板、设置、书架、用量、更多菜单、阅读设置）+ 视觉模型逐图评审 + DOM/对比度/触控/性能审计脚本 + 源码体系盘点 + 5 个参考站实抓 token（`docs/UI-DESIGN-LANGUAGE-RESEARCH.md`）。

## 1. 现状诊断

### 1.1 量化体检（改造前基线）

| 指标 | 实测 | 判定 |
|---|---|---|
| 首次内容渲染 FCP | 52ms（本机）；37 请求 / 760KB | 快，但 3 个字体 CSS（约 330KB）经 `@import` 串行阻塞渲染 |
| 颜色值 | 115 个不同硬编码色值 / 184 处 | 碎片化：蓝、绿、琥珀、红、天青五族混用且无语义 |
| 字号 | 10–13px 共 7 种，`font-size: 10px` 15 处、`11px` 34 处 | 中文 10–11px 不可读，长时阅读疲劳 |
| 圆角 | 18 种取值（0/2/3/4/6/7/8/10/12/26/30/9999…） | 无规范，按钮近直角、卡片 6–12px 混杂 |
| 过渡 | 133 个交互元素中 122 个无任何 transition | 状态切换无反馈，"生硬" |
| 对比度 | 12 处低于 WCAG AA（如 `#687684` on `#f8fafc` = 4.45，10px on `#e4edf6` = 3.93） | 弱化文字大面积压线/不达标 |
| 触控目标 | 13 处 < 32px（「删除此块」48×20、「疑字·块 N」155×20、复选 13×13、滑块 28px） | 移动端误触率高 |
| 内联样式 | 70 个 `[style]` 元素 | 可接受（坐标定位类刚需） |

### 1.2 视觉模型逐屏评审的高频问题（收敛结论）

1. **色彩语义混乱**：同一蓝色承担链接/主操作/选中态/成功态至少 6 种语义；橙色横幅承载「处理追溯：页 1 通道 paddle-aistudio+qwen-assist 版式 auto PDF 指纹…」这类开发者信息，被误读为报错；`有 0 待核对文字` 在计数为 0 时仍用警示色，制造假警报。
2. **视觉层级倒置**：顶栏一行塞入约 12 个信息块（品牌+书架+4 按钮+费用+配置+2 低频入口）；首屏被黄色追溯条占据，而真正主角（书稿正文）权重最弱。"工具开发者视角，而非古籍阅读者视角"。
3. **组件不一致**：按钮实底/描边/文字链三套并存且主次不分（「导入 PDF」比「导出离线书」更像主按钮）；原生 select、自绘按钮、文字链混搭；占位文本与真实值同色。
4. **状态表达不足**：「已保存 / 待核对 / 处理进度 / 阅读进度」四种状态并列但语义不分层；无脏状态局部反馈；进度双条（处理 12% vs 阅读 0%）同色难辨。
5. **可点击性弱**：目录条目无 hover 线索；十余处纯文字链无下划线；进度滑块手柄 8px 几乎不可见；删除块按钮 20px 高且紧贴标题。
6. **移动端密度**：校对栏 390px 下把「类型/阅读顺序/排向/左上宽高%」全部平铺，核心动作（改字、保存）被元数据淹没；技术 slug（`paddle-aistudio`）直接暴露给用户。
7. **动效缺失**：开合、切换、保存等全部瞬时完成，无进入/退出节奏；（同时存在反向风险：既有 U1 规范禁止持续脉冲/流光，改造需保持"安静"。）

## 2. 方案：设计令牌「宣纸墨青」

设计语言一句话：**书案（米灰）→ 面板（暖白）→ 书稿（宣纸）三层纸感 + 松烟墨三级文字 + 青碧主色 + 黛蓝辅色 + 秋香/赭朱/苔绿语义色**，全部低饱和、暖基调，长时间阅读不刺眼；校对疑点用「朱批」红点缀，呼应古籍勘误意象。

### 2.1 配色（浅色默认 + 月白 + 夜阑；阅读纸色 3 款）

| 令牌 | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--bg` 书案 | `#EAE6DC` | 工作区底 | — |
| `--surface` 面板 | `#FCFAF4` | 侧栏/顶栏/卡片 | — |
| `--paper` 纸面 | `#FFEFA` 系 | 输入/浮层 | — |
| `--reading-paper` 书稿 | `#F7F3EA` | 阅读纸面 | — |
| `--ink` 松烟墨 | `#2E2B25` | 正文 | 12.7:1 ✓ |
| `--ink-soft` | `#5C564A` | 次级 | 6.5:1 ✓ |
| `--muted` | `#6D675B` | 弱化 | ≥4.5:1 ✓ |
| `--ink-3` | `#948E7F` | 占位/禁用 | 非必要信息 |
| `--primary` 青碧 | `#3D6A5A` | 主操作/当前项/进度 | 5.6:1；白字于其上 6.2:1 ✓ |
| `--info` 黛蓝 | `#45607A` | 链接/引用/坐标 | 5.9:1 ✓ |
| `--caution` 秋香 | `#A07A2E` | 疑似/待定 | tinted 底上用 `--caution-text #7D5C21` |
| `--danger` 赭朱 | `#A34A3A` | 错误/删除（tinted 不用实底红） | 5.3:1 ✓ |
| `--success` 苔绿 | `#456D3D` | 已校/通过 | ≥4.5:1 ✓ |
| `--mark` 荧光 | `#EFE3A8` | 证据定位/选区 | — |
| 线三级 | `#E7E2D5 / #DCD6C8 / #C5BEAE` | 纸边 | — |

- **主题**：`paper` 宣纸（默认）｜`clear` 月白（近旧版冷调）｜`night` 夜阑（深色长读，全套暖墨反相，已验对比度）。
- **书稿纸色**（阅读设置内独立于主题）：宣纸 `#F7F3EA` / 米黄 `#F5EDD8` / 豆沙绿 `#E6EFDF`（豆沙绿即传统"护眼绿"的低饱和收敛版），选择记忆在本地。
- 色彩规则（来自 shadcn/beui 共识）：语义色一律 **tinted 底 + 深色字**，实底只留给主按钮；颜色不作唯一状态依据（文字始终在场）。

### 2.2 排版（rareui"衬线读书稿 + 无衬线做 UI"+ shadcn typeset-reading）

- 书稿：衬线（系统宋体 → 内置 Noto 宋体回退），默认 20px/1.8（用户可调 15–30），`letter-spacing: .01em`；正文行长上限 36em（既有 U1 约束保留）。
- UI 字阶收敛到 7 级（12/13/14/16/20/24/28）；**最小字号 12px**（原 10/11px 全部提升）；页码/计数/坐标 `tabular-nums + --mono`。
- 字重归一 400/500/600/700（原 620/650/750 消除）。

### 2.3 圆角 / 阴影 / 边框（beautifului 发丝环体系）

- 圆角语义五级：chip 6 / control 8 / card 10 / panel 12 / window 14（原 18 种收敛；书稿纸面保持 2px"纸感"直角）。
- **层级靠底色差 + 1px 线**；投影只给浮层：`--shadow-hairline 0 0 0 1px` + 羽化分层 `--shadow-card/-paper/-dialog`；**书稿纸面零投影 + 1px 纸边**（原大面积投影取消）。
- 焦点环全站统一 `3px color-mix(primary 30%)`（shadcn ring-3）。

### 2.4 动效（transitions.dev 刻度，服从 U1"安静阅读"约束）

- 令牌：`--duration-micro 80 / quick 150 / fast 250 / medium 350 / slow 400 / stagger 40`ms；`--ease-standard cubic-bezier(.22,1,.36,1)` / `--ease-enter (.16,1,.3,1)` / `--ease-pop`（仅徽标）。
- 场景：按钮/行 hover 150ms；浮层**开 250ms（scale .96→1 + 淡入）、关 150ms（慢进快出）**；toast 进 350ms；开关只动 transform 250ms；主题换色 250ms。
- 红线（相对流行做法的取舍）：**书稿正文区零动画**；无持续脉冲/流光/呼吸灯（U1 门禁延续）；无玻璃拟态正文、无 3D tilt、无文字扰动、无回弹过冲（`--ease-pop` 仅限小徽标）、无 >500ms 或循环动画（加载 shimmer 例外）；`prefers-reduced-motion` 全局降级保留。

### 2.5 组件规范

- **按钮四级**：primary 实底（每屏唯一主操作）/ default 描边 / quiet 幽灵 / danger **tinted**（`danger-pale` 底 + 赭朱字，实底红仅确认框）；统一 hover（tint 底）/ active（1px 位移）/ disabled。
- **状态徽标**：chip 6px + tinted 四态（待核对=秋香 / 已校=苔绿 / 处理中=黛蓝 / 失败=赭朱）；**计数为 0 自动回中性**（`.issue-workbench.is-clear`），不再假警报。
- **列表行**（目录/搜索/疑点）：整行可点 + hover tint + 当前项左侧 2px 主色条；页码等宽字体。
- **链接/文字操作**：下划线（35% 淡入，hover 实色）+ 最小 32px 触控高度。
- **浮层**：`--radius-window` + `--shadow-dialog` + 遮罩 `rgb(46 43 37 / .35) + blur(2px)`（研究建议 .18 过弱，评审显示旧 .4 不足聚焦，取中）。
- **滑块**：手柄 14px + 阴影、热区 32px+；进度条 6px 胶圆。

### 2.6 易用性修复（评审 P0/P1 直接落地）

1. **技术信息归位**：「处理追溯（通道/版式/PDF 指纹）」不再进阅读首屏横幅，移入质量徽标「详情」诊断区（延续 U1"诊断分层"）；前端文件里的 provider slug 仍保留在校对块标题（校对者语境），阅读界面不出现。
2. **对比度**：弱化文字全部 ≥4.5:1（`--muted #6D675B`）；小字不再压线。
3. **触控目标**：删除/块标题/疑点列表按钮提到 ≥32px（桌面）/44px（移动，既有规则保留）。
4. **状态可读**：保存状态（待保存/保存中/已保存/冲突）色 + 文字双通道；处理进度 vs 阅读进度分色（黛蓝 vs 青碧）并保留不同标签。
5. **主题与纸色**进入「阅读设置」，本地记忆，刷新无闪白（head 内联预应用）。

### 2.7 性能

1. **字体 CSS 非阻塞**：`reader-fonts.css`（含 3 个 `@import`，约 330KB）改 `preload as=style` 异步加载，首屏只依赖 `styles.css`；系统字体先行、内置子集无感替换（离线导出书不受影响，仍同步加载）。
2. **滑块免重渲**：字号/行距拖动期间只写 CSS 变量（`--reading-size/--reading-leading`）即时反馈，松手（change）才重排一次并保存；消除每帧整页重建。
3. 既有良好实践保留：LRU 8 页缓存、快速翻页 Abort、图片 `loading=lazy`、按需证据升级。

## 4. 验证（实测）

| 项 | 改造前 | 改造后 |
|---|---|---|
| WCAG AA 对比度违规 | 12 处 | **0 处**（含半透明底逐层合成核算） |
| 控件边框非文本对比（1.4.11） | 1.5–1.9:1 | **≥3:1**（`--border-control`） |
| 触控目标（桌面 ≥32 / 移动 ≥44） | 13 处过小 | **0 处**（余隐藏 file input，命中区为外层 label） |
| 无过渡交互元素 | 122 / 133 | **1 / 130** |
| FCP（冷缓存本机） | 68ms（字体 CSS 阻塞） | **28ms**（字体非阻塞后） |
| 硬编码颜色 / 圆角 / 字重 | 115 色 / 18 圆角 / 3 种非标字重 | 语义令牌 / 5 级 / 400–700 |
| 390px 横向溢出 | 工具栏标签截断 | **无溢出**（工具栏换行，标签完整） |

- 静态门禁：`UxU1ReaderQuietTest`（禁脉冲/保留 reduced-motion）、`UxU3/UxU4/UxU6CloseoutTest`、`ExportServiceTest` 及全量 `studio.bookhtml.service.*Test` 全绿；`node --check` 全部前端文件；`probe_reader_fonts.js` 325 资产校验通过。
- 浏览器实测：1440/390 双分辨率逐屏截图（改造前后对照，`/tmp/ux-audit/`）+ 视觉模型逐屏复评；三主题 × 三纸色切换与刷新记忆实测通过；`prefers-reduced-motion` 保留。
- 既有 U 系列验收原则回归：阅读区安静（无浮层遮正文/无持续动画）、默认阅读模式、状态以文字为准（颜色不作唯一依据）、44px 移动触控、保存状态四态。
- 已知遗留（记入后续迭代）：移动端两组 Tab（视图切换 / 主操作）层级可再拉开；目录当前页与阅读进度联动高亮；「识别原文 vs 简体」差异高亮属功能增强，另立任务。
