      文字识别

      只从以下两条通道选择。识别会向所选服务发送 PDF 页面图像。

      默认通道

      PaddleOCR-VL-1.6

      打开飞桨 AI Studio，登录后创建 Access Token，粘贴到下方。保存只表示本地配置完整，不代表已连通或有可用额度。

      PP-OCRv6

      查看百度智能云 OCR 接入说明，创建应用并取得 API Key 和 Secret Key。接口地址由工具固定，不在这里修改。

      Qwen 结构整理与疑点建议

      独立于 OCR；只建议阅读顺序、分类和疑点，不自动覆盖原文。

      开启 Qwen 结构整理与疑点建议服务 这是 Qwen 服务的总开关。开启后可在转换时提取段落结构并针对上下文疑点生成纠错建议。

      在百炼获取 API Key 指南查看创建步骤；Key、模型与服务区域须匹配。启用后，处理时仍需主动勾选 Qwen，可能产生云服务用量。

      业务空间接入（选填）

      在控制台创建 Key 的弹窗或业务空间管理页查看 API Host；只填 Host 最前一段，例如 llm-xxx，不要填写完整网址。留空使用该区域的现有 DashScope 地址。

      JEV 候选比较

      模型: jev-1.13.0

      使用 TypeSafe JEV 大语言决策模型对 OCR 疑点进行多候选评估与置信度对比。

      开启 JEV 候选比较服务（总开关） 这是 JEV 的总开关。开启后可在疑点校对栏评估模型候选词；需填入下方 API Key 及模型参数。

      在TypeSafe 控制台创建 API Key。候选比较仍受校准状态、调用预算和外发许可约束；不满足门槛时继续人工校对。

      预算单位是工具的本地调用核算单位，不代表美元、人民币或供应商硬金额上限。

      费用估算参考单价（可选）

      按自己的套餐填单价；全部留空即费用未知。OCR 填每次送识请求价格，Qwen/JEV 填每百万输入、输出 token 价格。只与通道和模型完全匹配时估算，保存时快照；改价不会重写旧记录。没有供应商实付回传时，这不是账单。

      随读识别

      只准备当前页和前后各 5 页；翻页后停留约 1 秒才送识。阅读不等待识别，未完成时照常显示原稿。

      开启后可能产生云服务用量。已识别并缓存的页面不会重复送识；本次选择固定到停止为止。关闭页面或切换书籍将停止新任务，已送出的当前页可能完成。
