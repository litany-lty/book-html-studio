# 纸页工坊

独立的 Java 与网页应用，将 PDF 转为可校对、可搜索、可繁简切换的 HTML 书籍。网页由 Java 服务直接提供，不需要 Node、前端构建工具或外部数据库。

## 运行

需要 JDK 17 或更高版本和 Maven 3.6.3+；开发验收建议使用 JDK 17。当前界面的两条云端 OCR 流程不依赖 Tesseract，无需先安装本地 OCR 或前端依赖。

```bash
cd book-html-studio
bash run.sh
```

`run.sh` 每次都会先使用同一个 JDK 执行 `mvn -q -DskipTests package`，构建成功后才停止并替换由本项目脚本启动的旧服务；构建失败不会停止旧服务或启动旧包。`--build` 参数继续兼容，但现在可直接运行 `bash run.sh`。打开 `http://127.0.0.1:18765`，使用文件上传入口导入 PDF。应用默认仅本机可访问；前台运行时按 `Ctrl+C` 停止。

脚本会让 Maven 与 Java 使用同一个 JDK：优先采用当前终端显式设置的 JDK 17 或更高版本 `JAVA_HOME`，未设置时在 macOS 通过 `/usr/libexec/java_home -v 17` 自动选择 JDK 17。本机常见路径为 `/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home`；不修改全局 Java 配置。

端口默认读取 `.env` 中的 `PORT`（默认 `18765`），也可在命令行传入 `--server.port=19000`。构建成功后将 JAR 按 SHA256 放入 `.run-runtime/`，从只读固定版本副本启动，后续 Maven 打包不会覆盖在用文件。脚本只会向“工作目录属于本项目、使用本项目构建包或运行副本、占用目标端口”的旧 Java 服务发送 `TERM`，并等待其有界退出；未知端口占用者不会被终止，也不会使用 `pkill` 或默认强制结束。并发执行会由项目内启动锁串行保护，历史运行副本不自动删除。

PDF 预览、OCR 输入及原稿裁图共用渲染器，已包含 JPEG 2000（JPX）与 JBIG2 解码支持。遇到内嵌图像解码失败时会明确报错，不继续将错误的空白图提交给 OCR；真正的空白页仍可正常预览。渲染前检查页面尺寸并限制输出像素量和单边长度，异常尺寸会明确拒绝；这不代表能修复所有损坏 PDF 或保证所有内嵌资源的内存开销。升级后需要重启应用，已有失败页可指定页码重新识别，无需勾选“覆盖已有识别与校对结果”。

## 识别与阅读

1. 导入 PDF，先预览文字方向、跨页扫描及图表密集的代表页。
2. 可开启“随读识别”边读边识别，无需等待全书；也可在“处理设置”批量识别指定页，默认范围为第 `1-20` 页。两种模式都须主动开启，导入不会自动消耗云额度。文字型 PDF 优先读取可信文字层；扫描页使用所选识别提供商。页范围也可写 `1,3,25` 或其他区间，只有主动选择才会处理全书。
3. 默认进入横排阅读；可随时切回原稿或原貌 HTML。书中的原文与简体分别保存，原稿图保持原样。
4. 校对疑字、阅读顺序、块类型与坐标；遗漏的插图可补充图框。标为已校对代表人工确认，不代表自动 OCR 置信度。
5. 扩大识别页范围，完成后导出 ZIP，解压后直接打开 `index.html`。未处理、未校对页面会明确提示。

大文件导入时会显示等待状态，初始化全部页面后才出现在书架。若连接中断或超时，先点“刷新书架”核对结果，不要立即重复上传。任务轮询中断会提示“状态尚不确定”，暂停新任务提交并尝试恢复查询；此时应核对状态，不代表后台已停止。取消入口在任务标题栏持续可见；只有旧处理线程确实退出，才允许下一任务开始。失败/中断后可展开全部错误并调整页码继续，默认不覆盖已识别或手工修改的页面。

顶栏的“管理书架”（手机在“更多”中）提供搜索、按书名/导入时间/处理进度排序、改名、归档、恢复和逐本查看用量。归档仅从常用书架隐藏；原 PDF、识别结果、校对内容和费用记录仍保留，可在“已归档”页恢复。识别任务或随读窗口工作时不能归档该书；改名不改变原 PDF 文件名或已有书籍 ID。

原貌视图依据坐标近似排版；横排阅读按模型还原的真实语义顺序排列，适合调整字体与手机阅读。传统竖排页的识别顺序仍按右至左、栏内上至下处理，但阅读正文不会倒排或继续使用竖排。命盘、复杂图表与公式保留原方向的原图裁片，并可保留识别文字供搜索和校对。图片中的原始字形不会被静默改绘。

阅读目录根据已解析正文的标题块自动生成，按正文顺序与标题层级展示；原书目录页仍保留在书中，但目录恢复条目和“目录”标题不会成为导航章节。无标题页不再生成占位目录项，同一页的多个标题可以分别点击定位，续页沿用前一个章节。尚未识别为标题的文字不会被工具凭空编成章节；处理更多页面后目录随结果更新。运行版和离线导出使用同一套提取规则。

底部分页保留上一页、下一页和页码输入，并增加阅读进度滑块：拖动时预览目标页，松开后跳转，也支持点击与键盘调节。进度以当前阅读范围的首页为0%、末页为100%（仅一页时为100%并禁用滑块），表示页位置，不代表OCR完成率；选页导出的范围只包括导出页。目录、书签和页码跳转会同步进度。

### 随读识别：当前页与前后 5 页

翻页立即读取缓存或展示原稿，不必等待 OCR。停留满 **1 秒**后，开启的随读模式才派发识别：先当前页，再下一页、上一页，依次扩展到前后各 5 页（首尾自动缩小范围）。快速跳页时重置等待时间、替换尚未执行的旧队列；已经发送的云请求会正常收尾并保留结果，无法承诺撤销或免除费用，完成后才轮到最新目标页。

随读模式默认关闭，确认开启时使用选定的 OCR 通道及明确勾选的 Qwen 辅助；可以随时停止。已完成、已校对和手工内容不会被自动覆盖，失败页不会因来回翻页反复重试。需要重试失败页时，先关闭随读，再在“处理设置”指定页码处理。随读窗口与手动批量任务互斥，也不会抢占另一标签页的识别任务。

识别结果逐页到达即可阅读，不必等整个窗口完成。正在编辑、保存或处理冲突时，新结果只提示更新，不覆盖草稿。窗口内仅预取轻量页面数据，高清原稿仍按当前页加载；浏览器缓存有数量上限，不将整本扫描书装进内存。此功能属于在线工具，离线导出仅包含已经生成的结果，不调用 OCR。

切换书籍、离开页面或标签页转入后台会停止新的随读派发；断网时服务端租约到期也会清空待执行队列。刷新页面或重启工具后须重新明确开启，不自动恢复云调用。所有实际云请求仍记入“本书用量与费用”，与批量识别和重复解析累计在同一本书中；预读本地已有结果不产生模型费用。

### 阅读设置与字体

“阅读设置”集中调整字体、字号、行距、原文/简体、专注模式与阅读依据，字体可即时预览。桌面与手机均使用独立弹层，正文不必为低频设置让出多行空间。手机顶栏的“更多”包含导入、导出、本书用量与费用、工具配置；空书架也支持拖入一份 PDF，导入不会自动识别。

校对栏与正文的“文字依据”使用同一份疑点原图：保留真实比例，长竖列在预览区内滚动，点击可放大；只有可靠的逐字定位才显示红框。长 OCR、推测和判断依据可展开，编辑与确认操作优先呈现。切换疑点保留当前页输入草稿，包括有意清空的文字；“标记解决”仍需点击“保存整页”才写入。页面与保存栏常驻显示未保存、保存中、已保存或冲突，不把“已保存”当作“已校对”。

字体提供系统宋体、系统黑体、Noto 宋体、Noto 黑体、霞鹜文楷及 [JetBrains Mono](https://www.jetbrains.com/zh-cn/lp/mono/)。JetBrains Mono 仅覆盖英文、数字等字形，中文使用内置 Noto 宋体；原稿图片与坐标原貌不受字体切换影响。选择保存在当前浏览器本地；禁止本地存储时仍可临时切换。在线工具与新导出的离线书共用选择逻辑，四套第三方字体、OFL 许可与本地子集全部随应用及 ZIP 打包（约 10.7 MB），不向外部字体 CDN 请求资源。已有旧版 ZIP 需要重新导出才能获得新功能。

### 本书用量与费用

打开一本书后，点击顶栏 **本书用量与费用**（手机为“更多 → 本书用量与费用”），可查看累计请求、各模型用量、估算金额及分页调用明细。记录以书籍 ID 为单位长期保存，重跑整书、覆盖结果、局部复识别、结构辅助及 JEV 比较不会清零；另行导入的新书 ID 是独立账本。已完成 OCR 缓存复用单列，不重复当作外呼计费，鉴权与异步任务轮询也不当作新 OCR 请求。查看既有 JEV 建议不会增加外呼次数，但本期不逐次统计这类历史建议读取。明细分页固定本次读取范围，新调用在刷新后进入列表。

供应商通常只返回调用结果或 Token 用量，而非实际扣款。本工具不读取供应商账单；在“工具配置 → 费用估算”可按自己的套餐填写参考单价，OCR 按每次送识图片/请求、Qwen/JEV 按每百万输入与输出 Token 估算。跨页拆图可能一书页产生多次请求。估算单价必须与模型匹配，每次调用保存当时的价格快照，后续改价不重写历史，人民币与美元分开合计。未填单价、缺失用量、超时或结果未知会明确标示，不按零元计算；参考单价不自动处理供应商赠送额度、阶梯价或折扣，实付请核对控制台。

仅统计启用记录后的调用，旧版没有留存的历史费用不猜补。记录位于 `data/books/<书籍ID>/usage/`，不随识别任务重建或页面覆盖删除；账本损坏时会报错并阻止新的未记账外呼，不清空继续。记录不含书中文字、图片、Key 或供应商原始响应；离线导出不包含本机费用和密钥设置。

## 界面配置：两条 OCR、Qwen 辅助、可选 JEV

从顶栏的 **工具配置** 打开设置，按页面内的获取凭据链接填写。保存只更新本机配置，不会发送测试图或自动开始识别；“已配置”不等于已验证云端额度。当前新任务只提供两条 OCR 通道：

| 通道 | 凭据及获取入口 | 用途 |
| --- | --- | --- |
| PaddleOCR-VL-1.6（飞桨 AI Studio） | [AI Studio PaddleOCR](https://aistudio.baidu.com/paddleocr) 的 Access Token | 默认通道；文字与版面结构提取 |
| PP-OCRv6（百度智能云应用） | [百度智能云 OCR](https://console.bce.baidu.com/ai/#/ai/ocr/overview/index) 应用的 API Key 与 Secret Key | 通用文字识别，独立账户额度 |

PP-OCRv6 的[官方请求地址](https://cloud.baidu.com/doc/OCR/s/6mncwkr9c)仍是 `pp_ocrv5`；不能仅按接口路径推断返回模型版本。本项目对 `pp_ocrv6` 的一次官方示例图请求收到 `Unsupported openapi method`，故使用文档地址。旧 `paddle`、Qwen OCR、MiniMax、本地 OCR 的历史结果仍可阅读，但不再作为新任务可选通道。

**结构整理与疑点建议** 单独配置 Qwen：启用开关、API Key、地域、模型及可选 Workspace ID。先在[百炼控制台创建 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)，选择与密钥、模型一致的地域。地址只从官方地域与工作空间规则派生，不能填任意代理地址。默认模型名沿用 `qwen3.8-max`，请以自己工作空间实际开放的图片输入、结构化输出模型为准。阿里云[地域说明](https://help.aliyun.com/zh/model-studio/regions)将旧 DashScope 域名列为兼容方式，并说明 2026-09-30 后不再提供新增功能；已具备工作空间 ID 时可填写以使用推荐域名。

**JEV 是可选功能，默认关闭。** 可在 [TypeSafe 控制台](https://console.typesafe.ai/keys)创建 Key，填写模型、明确允许外发和本地调用核算上限后启用候选比较。界面开启不会将未校准模型升级为 ASSIST，也不会开放未经门禁的自动确认。JEV 的“调用核算单位”不是人民币或美元；金额在“本书用量与费用”单独展示。本期比较已有候选，不再通过旧环境变量隐式发起 Qwen OCR 局部复识别。

已保存的密钥不会回显；输入留空表示保留，只有勾选明确的清除操作才删除。设置保存在 `data/.settings/settings.json`（以实际 `BOOK_DATA_DIR` 为准），目录权限 `0700`、文件 `0600`，是本机私有明文而非加密保险箱，不进入源码或离线导出。界面配置优先于 `.env`，清除后也不会重新启用旧环境值。可用 `.env.example` 初始化配置，但之后应以界面为准。任务排队、运行、取消收尾期间不能改设置，避免一次任务混用不同账户；设置文件损坏会拒绝启动而不静默回退。请备份数据目录并妥善保护设备账户。

跨通道回退默认关闭。只有明确开启并遇到额度/权限拒绝时才尝试另一条已配置的 OCR 通道，并在结果警告中说明；图片问题、一般解析失败或不确定提交不触发回退。两通道认证、缓存相互独立；缓存命中不验证 Token 有效性。AI Studio 已取得任务 ID 时重试只恢复查询，提交结果不确定时不自动重提；更换账户后不使用新凭据查询旧账户的未完成任务。切换设置不会重跑已有 READY 页面，需要重跑时仍须勾选覆盖并再次确认。实际额度、余额及是否共享以供应商控制台为准。

AI Studio 的 PaddleOCR-VL 按页提交异步识别任务；“尝试拆分跨页扫描”默认开启，会先拆分双页扫描再分别识别，关闭时保留整页原生布局和图表区域。目录页按右上、右下、左上、左下四个分区检查竖栏覆盖并恢复缺失条目，再按传统竖排的右页优先、栏内从上到下组织横排阅读顺序。[Qwen3.8-Max](https://help.aliyun.com/zh/model-studio/qwen3-8-max) 通过阿里云 [OpenAI 兼容 Chat Completions](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions) 接收完整页面和可信 OCR 来源块；辅助结果只允许给现有块排序、分类、标注标题层级及提出疑字建议。每个来源块必须恰好保留一次，正文、坐标和来源 ID 不允许由辅助模型覆盖；引用未知、重复或缺漏时整体回退到所选 OCR 通道的原结果。

普通页面流程为：所选 OCR 通道提取文字与布局 → 可选 Qwen3.8-Max 阅读顺序、块类型和疑点建议 → 确定性繁简转换 → 横排 HTML 阅读。普通辅助不覆盖 OCR 原文；未确认候选可以改善简体阅读稿，但始终保留疑点状态和原始 OCR，原文模式不会用候选冒充原字。目录恢复是独立分支：支持有可靠分隔线的四分区目录，以及本地检测到规则竖向点引线的单页目录（即使主 OCR 只返回空图）；后者按右至左分栏，在一次 Qwen 请求中恢复横排条目，并校验条目数与点引线证据。生成带 `qwen-toc-recovery` 来源的新块，原始 OCR `sourceRecords` 始终保留；覆盖率、区域或结构校验不通过则保留旧内容并告警，已发出恢复请求后不会再发一次普通辅助请求。条目数校验不等于逐字正确。旧 Qwen OCR、MiniMax 或本地 Tesseract 不会作为自动跨通道 fallback；Paddle 系额度降级边界见上文。

近空白页面若同时出现极低图像信息与不相称的满页表格/图形文字，工具会保守显示原页图并告警，不将该文字铺成正文；原始识别记录仍保留。这不是“自动判定空白”，也不会把浅色文字直接删除。

阅读层保留目录“标题…页码”的逐条换行，普通正文仍合并扫描换行。对于明显重复的短单元格 OCR、失去行列关系的多组命造或箭头关系图，保守展示对应原图裁块，识别文字与疑点可展开；不会把循环重复的结果当成连贯正文，也不凭规则猜回表格数值。这是展示层处理，源文字、坐标和原始记录不改写，已确认内容不自动重新分类。

目录使用“标题 / 页码”时同样保留条目，正文中 OCR 生成的完整下划线文字/圈号注脚格式壳会转成可读文字，不解释任意公式或执行模型生成代码。双页扫描仅在宽页、两边竖排正文、可靠连续页码与中缝边界同时成立时修正跨页穿插，保留各半页内部顺序；证据不足不强排。

调用组合流程会将页面图片发送给明确选择的 OCR 通道；启用辅助时还会发送给阿里云 Qwen，并分别消耗对应账户用量。界面展示的 `quotaSource` 只说明认证账户通道，不查询或承诺余额、共享额度与免费次数。每页最多进行一次 Qwen 结构辅助，不自动重试计费。取消会停止本地处理或等待，但不能保证撤销已经提交的远端任务及计费。默认先处理前 20 页供检查，再由用户决定是否扩大范围。本轮双通道接线与界面验证不包含真实收费调用。

Qwen3.8-Max 官方模型页标明支持图片输入与结构化输出；本项目显式关闭思考模式并请求 JSON Object，以减少结构辅助耗时和额外推理用量。宽度达到 1800 像素的页面会在同一次辅助请求中保留完整页 overview，并按图像预算附加最多四个有内容的高分辨率象限；每个分区都携带完整页归一化坐标，来源块坐标仍以 overview 为准。任一分区超过单图或总预算时整组退回仅 overview，不会额外发起计费请求。

模型只有在原图确实模糊、破损或遮挡时才应标记 `unreadable`；普通错字或低置信度只作为 `suspected` 疑点。正文默认保真显示来源文字；原文/简体与“是否显示辅助推荐”是独立设置。只有显式开启辅助阅读且存在符合门槛的有效推荐时才显示未确认推荐，模型候选不会自动标为已解决。点击疑点打开证据浮层，按自然比例显示文字所在的整行或竖列，并按原页坐标给可靠定位的疑字加红框；长竖列在证据区域内滚动并自动居中到目标，不带动阅读页。只能定位到行或段、或缺少可靠逐字坐标时，不绘制疑字框并明确说明定位粒度。原始 OCR、候选和模型依据可在“识别详情”中展开，精确字词小图折叠在“查看字词小图”中，点击“修改”进入完整校对。

横排展示仅在渲染层整理换行，不修改 OCR 原文或疑点索引：普通中文正文的单换行会拼接，真正的双换行和内容块边界会保留；`qwen-toc-recovery`、`paddle-span` 的目录条目换行保持不变。相邻普通正文块只在逗号、顿号明确续句，或两个竖排块的坐标证明文字从扫描件右半页跨到左半页时合并；短标签、列表、封面署名、星名条目、标题、图注和图像仍保持独立位置。

当前页的校对侧栏仍集中列出内容疑点，并提供原图区域、只读 OCR、推测候选和当前编辑对照，可逐项上一处/下一处、采用推测并确认、标记解决或恢复未解决；离线阅读器的修改继续保存在浏览器本地。所有模型文字都按纯文本呈现。关闭轻量证据浮层会恢复触发位置与焦点，手机使用底部 sheet，避免打断阅读位置。若直接修改整段原文或简体导致范围失效，原疑点依据、推测和编辑值会先转存为块级待复核说明，再清除旧范围，避免把过期索引套到新文字。自动完成不代表逐字无误；用户可直接阅读，也可按需校对。`reviewed` 只表示人工确认，系统不会把自动页伪装成已人工校对。

舒适阅读始终完整显示 `figure`、`table`、`formula` 的原图裁片。对于主 OCR 误归为普通文本、但具备多行重复箭头或密集竖线连接证据的未校对关系图，运行版与离线导出也按相同规则显示局部原图，不猜造对应关系、不回写原始数据。视觉块自身的 OCR 转录保留在可搜索、可展开的“图内识别文字”中，并继续支持疑点点击与校对，避免把整张命盘或表格的长段 OCR 误当正文铺开；只有独立的 `caption` 块作为真实题注直接显示。原始 OCR 数据不会因折叠展示而丢失。编号列表及横排短标题下的平行短条目保留换行，普通正文仍合并扫描换行。

## 质量与适应范围

### 广告干扰

工具会对独立的页边短文字块作保守广告识别：同时具有明确推广语、联系方式/账号、与正文分离的页边位置，才标为 `advertisement`。横排阅读与导出默认收起这类广告，搜索与目录不把它们当正文；页内“已过滤…处广告 · 查看”可展开原识别字并定位原稿，校对栏也可将块类型改回正文。源 PDF、原始识别记录、原字和坐标不删除。已人工校对的内容不会被自动重新分类。

仅有网址、电话、页眉、出版信息、二维码或正文中的相关讨论，不会仅凭关键词移除。与正文混在同一大块、覆盖正文或缺乏可靠定位的广告可能仍需核对；本功能不修复被遮住的字，也不是 PDF 图片去水印。对于扫描书只有广告/水印文字层的情况，覆盖不足检查优先改走图像识别，预览异常不会静默把少量广告当成完整正文。

转换结果采用统一的页面和内容块数据，保存坐标、阅读顺序、繁体原文、简体文本、来源与校对状态；识别提供商与页面渲染相互独立。按页保存使长书可以分批处理、失败重试和恢复中断后的工作。

工具本身按上述 OCR 与辅助流程自动生成结果，不会把人工修字伪装成自动准确率。仓库当前前 20 页样本中保留了 9 处历史外部视觉校对候选，用于界面与证据链验收；它们不是现行自动管线生成的准确率证据，也不会被静默标为人工确认。后续导出由通用 `ExportService` 根据页面数据生成，不依赖手工修改固定样页 HTML。

清晰的文字层、横排印刷稿、竖排印刷稿、跨页扫描、图文混排分别走对应路径。局部残损、手写、图案遮挡、特殊符号、复杂阅读顺序以及图中文字都需要检查。模型返回的置信度不是经过标定的准确率，自动完成不等于文字已正确。

《中国绝学第01集》实测为 482 页扫描 PDF，抽查页没有文字层，包含双页合扫、繁体竖排、命盘和手写稿。本地 Tesseract 在该书复杂样页上有明显错字，应视为待校对初稿；高质量交付需要视觉模型样页验证及人工校对依据。工具不使用语言模型凭空补字或改写原书。

历史早期验证曾只处理第 1、25、100 页，当时 3 页均未人工校对、另 479 页待处理；该记录不是当前样本范围。第 100 页的手写与底纹遮挡曾导致明显错字，说明本工具不承诺无人值守即可得到出版级成书。强制重识别若发现新来源文字量显著缩水，会拒绝静默覆盖已有完整页并保留安全失败信息。

前20页真实组合样本曾用于本地验证离线导出、疑点证据链和资源完整性；其中保留的历史外部视觉校对候选不是应用管线自动生成，也不代表人工确认或出版级准确率。样本包含原PDF与模型响应，因此不随源码仓库发布。请使用自己的PDF在本机复现并核验导出结果。

第25页已有的 Qwen OCR 与 MiniMax `cached-replay` 仅为旧流程历史验证，不代表新组合的识别效果；相关私有夹具不随仓库发布，对应测试在夹具缺失时会跳过。强制重试同一Paddle来源时，原文和简体均未改变的旧未解决疑点会保留，新重叠建议优先；已解决或手工来源不会自动迁移。

`data/` 保存上传原文件、页结果、任务状态、用量账本及私有界面设置，`.env` 可保存初始化配置；请自行备份并保护这些目录/文件。若部署到网络环境，应先增加身份认证、访问控制及上传配额；默认版本定位为本地独立工具，配置接口只允许本机同源请求。

### JR-14 原图盲标

`scripts/verification/render_blind_pilot.py` 可从本地试点 JSON、书目映射、OCR 定位记录与原 PDF 生成离线标注页（需要本机 `PyMuPDF`、`Pillow`）。例如：

```bash
python3 scripts/verification/render_blind_pilot.py \
  --pilot /tmp/jr14-pilot/pilot.json \
  --bookmap /tmp/eval-bookmap.json \
  --runs /tmp/eval-runs \
  --pdfdir /path/to/private-pdfs \
  --out /tmp/jr14-pilot/blind-board
```

示例中的 `/tmp` 路径与 PDF 目录均需替换为自己的本地试点材料。打开输出目录的 `index.html`，对照原 PDF 的整页和局部图填写原字、不可辨认或无法唯一判定；页面不展示候选或 JEV 结论。蓝框仅定位到 OCR 内容块，不是精确字框；遮蔽上下文只用于寻找位置，不能代替原图判断。标注在浏览器本地暂存，需点击“下载标注 JSON”保存；尚未完成的标注不会被当成准确率证据。生成的 PDF 裁图、私密正文和人工标签均保留在本机，不提交仓库。

标注可通过 `scripts/verification/apply_review_labels.py` 绑定回冻结集：

```bash
python3 scripts/verification/apply_review_labels.py \
  --dataset /path/to/private/pilot.json --labels /path/to/private/labels.json \
  --live /path/to/private/live.jsonl --board /path/to/private/board/board.json \
  --out /path/to/private/new-review-output
```

`--live`、`--board` 可选。工具校验数据集 SHA256、案例身份、标签状态和 B/C 候选集合身份，不覆盖已有标注或输出目录；标签必须显式声明 `reviewerType` 与 `reviewedByHuman`。AI 审阅只能生成探索性结果，不能冒充人工校准或自动批准 ASSIST。`NOT_TEXT`（换行、列间空白）单独统计，不计入识字准确率；缺少标注的案例也不会被误当“原图不可读”。采样时数字/否定风险取自争议文字本身，不借用邻近上下文来凑配额。

`scripts/verification/sample_books.py` 可在独立本地服务上复现有限抽页计划（本机需要 `requests`）：按私有 JSON 中的 PDF 路径和 `samples[].pdfPage` 导入、只处理明确选中的页面、导出样本；不重试不确定的提交、不自动覆盖，默认最多 24 页。仅对自己的隔离数据目录使用，不要指向日常书库。私有样本、标注和云响应应放在被忽略的 `verification/` 或其他私有目录，不提交 Git。

更新阅读器后，可用 `scripts/verification/export_sample_gallery.py --base http://127.0.0.1:18769 --report /path/to/private/samples/report.json --out /path/to/private/new-gallery` 通过工具重新导出全部已完成样页并生成阅读入口；这一步仅调用本地读取/导出接口，不重跑 OCR、不写回书籍、不覆盖旧的离线校对文件。
