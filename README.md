# 纸页工坊 (Book HTML Studio)

面向个人与受信任局域网的 **PDF 阅读工具**：部署一次，上传 PDF 保存到服务器，手机、平板和电脑以后都可回到同一个书架阅读。

首页以书架、查找和继续阅读为主；解析、疑点核对与离线导出是辅助能力，不要求读者先完成整书转换。支持原稿对照、横排阅读与繁简切换。
网页由内嵌 Java 服务直接驱动，**无需 Node.js、前端构建工具或外部数据库**，拉取代码即可一键启动使用。

## 快速开始

### 1. 环境要求
- **JDK 17 或更高版本**（开发验收推荐 JDK 17，macOS / Linux / Windows WSL 均支持）
- **Maven 3.6.3+**

当前界面的两条云端 OCR 通道不依赖 Tesseract，无需预先安装本地 OCR 或前端环境。

### 2. 一键启动

在项目根目录下直接执行：

```bash
cd book-html-studio
bash run.sh
```

- **开箱即用**：无需事先配置 `.env` 文件，脚本内置默认安全配置，拉取后可直接启动。
- **自动编译与热替换**：`run.sh` 每次启动时先自动执行 `mvn -q -DskipTests package`，构建成功后安全平滑替换旧服务（若构建失败则保留旧服务运行）。
- **多平台 Java 探测**：优先使用终端设置的 `JAVA_HOME`，未设置时在 macOS 自动通过 `/usr/libexec/java_home` 定位，在 Linux 自动根据 `PATH` 中的 `java` 解析 JDK 根路径。
- **端口与网卡监听**：默认监听端口 `18765`，绑定全部网卡（`0.0.0.0`），自动探测并打印本机及当前 Wi-Fi/局域网访问地址。

### 3. 命令行参数

`run.sh` 支持以下灵活参数：

| 参数 | 默认值 | 说明与示例 |
| --- | --- | --- |
| `--server.port=<端口>` | `18765`（或 `.env` 中的 `PORT`） | 自定义服务端口，如 `--server.port=19000` |
| `--lan` | 启用（`0.0.0.0`） | 开放局域网访问，受信任局域网设备可浏览共享书架 |
| `--local` | - | 仅限本机回环访问（绑定 `127.0.0.1`） |
| `--server.address=<IP>` / `--bind=<IP>` | `0.0.0.0` | 显式指定监听 IP 地址 |
| `--build` | - | 兼容参数（脚本默认已自动执行增量打包） |

### 4. 访问地址

启动成功后，终端将输出访问入口：
- **本机访问**：`http://127.0.0.1:18765`
- **局域网访问**：`http://<本机局域网IP>:18765`（手机或同一局域网下的平板/电脑直接在浏览器打开，无需安装 App）
- 前台运行时按 `Ctrl+C` 即可优雅停止服务。

## 局域网使用：打开书架，上传，阅读

**默认就是共享书架，不需要注册、登录、创建个人空间或设置共享开关。** 部署后，同一可信局域网的设备通过内网地址直接上传 PDF；之后随时回来选书，已上传文件无需重传。新增上传默认不再索取配对码，也不依赖临时上传 Cookie。

PDF、书籍目录和已发布正文保存在服务器；所有可访问书架的设备看到同一批未归档书籍。页码与书签只留在本浏览器，避免不同读者互相覆盖，不是私人书架。书架默认按本设备最近阅读排序，支持查找；从阅读页返回书架或重新切回书架标签时，会自动读取最新的轻量书单，不需手工配置同步。

普通阅读和上传没有模型设置步骤。未解析的扫描页先显示原稿；修改共享正文、归档、密钥与付费调用仍由有权限的部署者处理。默认自检在已授权的解析链路中运行，无需读者开启。

### 部署时只固定必要的数据目录

开发可直接用`run.sh`。常驻部署把构建好的JAR放在固定位置，**将`BOOK_DATA_DIR`指向独立的持久目录**，不要随每次发布替换或放在临时容器层：

```bash
BOOK_DATA_DIR=/srv/book-html-studio/data java -jar /opt/book-html-studio/book-html-studio.jar
```

默认端口是18765；同网设备打开`http://服务器内网IP:18765`。没有需要改动的情况不必设置额外端口、主机名或共享选项。Linux常驻服务示例见[`deploy/book-html-studio.service.example`](deploy/book-html-studio.service.example)，示例不包含密钥，也不会自动安装或重启服务。上传需等服务器确认成功；之后关浏览器或重启服务不删除书籍，重新启动后同一局域网仍可直接上传。

已有安装升级前备份整个私有数据目录，沿用原路径；不要只搬PDF，避免丢失识别、校对和任务记录。运行环境需允许服务账户写入该目录。书签/页码属于浏览器同源存储，改IP/端口、换浏览器或清理浏览数据会失去本地位置，但不会删除服务器书籍。

<details>
<summary>部署者才需要了解的访问边界</summary>

无需配对的上传仅适用于实际直连私网地址（IPv4私网/链路本地、IPv6 ULA/链路本地）。不会通过主机名、URL令牌或转发头猜测客户端属于局域网；公网、代理转发和不明确地址不自动取得上传权限。同源Origin/Referer、Host校验、文件大小/页数限制继续执行。这不是公网账号认证，禁止将服务裸露到公网；HTTP不加密，敏感环境应由部署者保护网络和HTTPS入口。

明确设置过`BOOK_LAN_READ_REQUIRES_PAIRING=true`的旧部署继续保留限制，不自动恢复或放宽已有授权。只有这些受限或非默认连接才出现“访问授权”入口；临时配对仍仅给READ+UPLOAD，不给EDIT/PAID/MANAGE。这是旧部署兼容，不是普通用户需要配置的新功能。

模型凭据仍从仓库外环境或现有加密存储读取；只有部署者启用云解析时才需要配置实际使用的通道，不要求填写所有模型。不要将密钥放入Git、unit或截图。采用反向代理、固定主机名等非默认部署时，需要部署者完成可信接入边界，不配置通配Host。

</details>

## 核心功能与使用流程

```
[ 共享书架 ] ──> [ 上传 PDF / 选择已有书籍 ] ──> [ 当前页阅读 / 继续上次位置 ]
                                      └─> [ 已授权解析与默认自检 / 按需校对 / 可选离线导出 ]
```

1. **导入与解析**：
   - 网页支持拖入或上传 PDF，自动提取页面尺寸与文字层。
   - 渲染器内置 JPEG 2000（JPX）与 JBIG2 解码支持；大文件在页面初始化完成后展示在书架上。
2. **随读识别（边读边识别）**：
   - 在具备付费处理权限与既有云授权的入口，打开书籍后可沿用随读识别；普通共享读者不会仅因阅读或上传就获得模型调用权限。
   - 未识别完成时照常显示高清原稿，无需等待全书转完即可顺畅开读。
   - 亦可在“处理设置”中手动指定页码范围（如 `1-20` 或 `1,3,25`）批量后台处理。
3. **阅读排版与繁简切换**：
   - **横排正文**：按模型还原的自然语义阅读顺序重排，适合现代屏幕与移动端阅读。
   - **原稿与原貌**：随时可一键切回扫描原图对照，或查看基于原始坐标近似排版的原貌 HTML。
   - **确定性繁简切换**：原文与简体分别保真存储，支持一键切换。
4. **疑点校对与证据链比对**：
   - 点击正文疑点弹出自然比例证据图浮层，定位疑字并标红框，支持长竖列滚动居中比对。
   - 支持逐项跳转下一处、采用推测候选、标记解决或整页修改保存。
   - 标为 `reviewed` 严格代表人工确认，系统绝不把模型候选冒充为已校对。
5. **单书离线打包导出**：
   - 识别与校对完成后，点击“导出书籍”即可生成包含完整 HTML、图片资源与离线阅读器的独立 ZIP 包。
   - **内置独立字体资产**：打包内置思源宋体、思源黑体、霞鹜文楷及 JetBrains Mono（约 10.7 MB），不依赖任何外部 CDN，解压后双击 `index.html` 即可永久离线阅读。
6. **书架管理与归档**：
   - 顶栏“管理书架”（移动端在“更多”菜单中）提供搜索、按书名/导入时间/进度排序、改名、归档与恢复功能。
   - 归档书籍从常用书架隐藏，原始文件、识别记录与用量账本完整保留。

## 识别通道与模型配置

部署者需要启用云解析时，从网页顶栏的 **工具配置** 打开设置窗口；普通读者不需要配置。配置保存在服务端本地，不发送无授权测试图；留空表示保留既有设置，只有显式勾选清除才会删除。

| 通道 / 功能 | 凭据及获取入口 | 用途与特性 |
| --- | --- | --- |
| **PaddleOCR-VL-1.6**<br>*(飞桨 AI Studio)* | [AI Studio PaddleOCR](https://aistudio.baidu.com/paddleocr)<br>创建 Access Token 填入 | **默认通道**；强大的文档文字与复杂版面结构提取，支持自动切分跨页扫描。 |
| **PP-OCRv6**<br>*(百度智能云)* | [百度智能云 OCR 控制台](https://console.bce.baidu.com/ai/#/ai/ocr/overview/index)<br>创建应用的 API Key 与 Secret Key | 通用文字识别通道，独立账户额度；接口地址由工具固定。 |
| **Qwen3.8-Max**<br>*(阿里云百炼)* | [百炼控制台创建 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)<br>配置 Key、模型名与官方地域 | **结构整理与疑点建议（可选辅助）**；利用多模态视觉模型优化阅读顺序、分析段落块、提供疑字辨识建议。 |
| **JEV 候选比较**<br>*(TypeSafe，可选)* | [TypeSafe 控制台创建 Key](https://console.typesafe.ai/keys) | 可选专家模型比较功能，默认关闭；支持设定外发配额上限。 |

> [!NOTE]
> - **跨通道回退**：默认关闭。只有明确开启且遇到配额/权限拒绝时，才尝试回退至另一条已配置的 OCR 通道。
> - **目录自动恢复**：针对带点引线或四分区版面的复杂古籍目录，系统可在原 OCR 仅提取图块时，结合多模态模型智能恢复章节标题与对应页码，同时保留原始切片证据。
> - **配置存储与安全**：默认 `ENV_ONLY` 模式（从运行环境读取）；亦可在 `.env` 中设置 `BOOK_SECRET_STORE_MODE=ENCRYPTED_FILE` 并注入主密钥，实现 Web 界面只写更新与 AES-256-GCM 密文落盘存储。

## 本书用量与费用账本

每本书均具备独立、可校验完整性的调用日志与用量账本（不是对任意本地攻击者的签名认证）：
- **明细可查**：点击顶栏 **本书用量与费用**，可逐页查看累计外呼次数、各模型 Token 消耗、图片请求数及价格快照。
- **自定义参考单价**：在“工具配置 → 费用估算”中可按所购套餐填写单价（人民币与美元独立合计）；未填单价或超时会明确标示，不误记为 0 元。
- **账本持久化**：账本位于 `data/books/<书籍ID>/usage/`，重跑任务或离线导出均不破坏已有消费凭据。

## 局域网访问与安全设计

1. **局域网免配对只读**：
   - 只要处于同一局域网/Wi-Fi，手机、平板或副电脑访问 `http://<局域网IP>:18765` 即可直接开读、选书、翻页，无需繁琐认证。
   - 前端已适配 HTTP 非安全上下文（Insecure Context），全面兼容 RFC 4122 v4 UUID 生成，移动端阅读无任何控制台脚本报错。
2. **写操作动态配对保护**：
   - 为防止同局域网其他设备未授权篡改数据或消耗付费云额度，局域网发起的写操作（如修改配置、删除书籍、启动付费批量任务）需先通过配对码授权。
   - 配对 PIN 码支持 5 次防暴力破解锁定机制（超限锁定 60 秒），本地回环访问全权限放行。
3. **安全边界**：
   - 严禁通配符 Host 访问，严格校验 Origin 与 Referer 同源头，开启 CSP 与 `no-store` 缓存保护。
   - **注意**：本项目设计为个人/工作室独立阅读工具，不含多用户账号体系。若需映射到公网环境，必须前置加挂具备鉴权保护的反向代理（如 Nginx + Basic Auth / Tailscale 等），不得将服务裸露在公网。

## 版面适应与特殊处理边界

- **广告与干扰过滤**：页边独立的推广语、联系方式等广告块会被保守识别为 `advertisement`，横排阅读与导出默认收起，但源图与原始文字记录均完整留存，可在校对栏中随时恢复为正文。
- **复杂图表与关系图保留**：遇到命盘、复杂表格、多行箭头关系图等易被 OCR 打碎的内容，阅读器会自动保留原图裁片，并将识别文字折叠至“图内文字”中，避免损坏版面语义。
- **双页扫描穿插修正**：仅在宽页、双页竖排、中缝边界及连续页码特征完整时执行跨页修正，保留各半页内部语义流向，证据不足时不强行拼合。
- **近空白页保护**：极低图像信息量但主 OCR 返回大量噪点字时，系统会保守展示原图并提示，防止将脏数据铺入正文。

## 开发与验证

项目内置了详尽的单元测试、集成验证与安全性回归检查：

```bash
# 运行核心安全性与能力测试
mvn -Dtest=WriteOriginFilterTest,LanCapabilityTest test

# 运行全量测试套件（828+ 用例）
mvn test

# 离线凭据安全扫描（检测当前追踪文件与可达历史是否有泄露）
python3 scripts/security/scan_secrets.py --history
```

### 离线盲标与复现脚本 (`scripts/verification/`)
- `render_blind_pilot.py`：基于本地原 PDF 生成离线双盲标注看板，用于评测 OCR 原始精度。
- `apply_review_labels.py`：将人工校验标签与基准数据集做 SHA256 绑定校验。
- `sample_books.py`：隔离复现有限抽页识别计划，便于快速测试单书样本。
